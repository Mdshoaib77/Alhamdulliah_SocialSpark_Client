# Social Spark - Community-Driven Event Management Platform

Welcome to **Social Spark**, a platform designed to help communities organize and track social service events such as road cleanups, tree plantation drives, and more. Users can create, join, and track social events in their local area.


Built with React, Tailwind CSS, Firebase, Express.js, and MongoDB, it offers secure authentication, dynamic issue tracking, contribution management, and a clean, responsive UI for a smooth user experience.

## Live Link
🌐 Live Site: https://alhamdulliah-social-spark-platform.netlify.app/

## 🧠 Overview

This platform allows users to:

- **Create Events**: Users can create social service events, including details like title, description, location, event type, and date.
- **Join Events**: Users can browse and join upcoming events.
- **Track Events**: See all events, manage the ones they created, and track their participation.
- **Event Management**: Admins or event creators can update or delete their own events.
- **Authentication**: Secure login and registration with Firebase (email/password, Google, or GitHub login).
- **Theme Customization**: Switch between dark and light themes to personalize the user experience.

## ✅ Features

- **User Authentication**: Secure login and registration with Firebase (email/password, Google, or GitHub login).
- **Event Creation**: Create an event with details like title, description, event type (Cleanup, Plantation, Donation), image URL, location, and date.
- **Join Events**: Browse and join upcoming events.
- **Manage Events**: Users can manage (edit or delete) events they’ve created.
- **Dark/Light Mode**: Switch between dark and light themes with the toggle button.
- **Event Filtering and Search**: Filter events by type and search for events by name.
- **PDF Reports**: Download a report of contributions in PDF format.
- **Responsive Design**: Fully responsive across desktop, tablet, and mobile.
- **Animations**: Smooth page transitions and UI animations powered by Framer Motion.


## 🎨 **UI & Theme**

- **Clean and modern UI** designed with **Tailwind CSS**.
- **Responsive design** for **desktop**, **tablet**, and **mobile**.
- **Optional dark/light theme toggle** to switch between themes based on user preference.
- **Accessibility-focused components** to ensure a smooth and inclusive user experience.
